# 任务（三步走）

## Step 1 · 构图形式识别（不占分，仅做准入判定 + 决定子项权重）

从下方「构图形式对照表」中识别画面**最匹配的一种构图形式**（写入 `composition_form`）。

- **属于给定 20 种之一**：`composition_form_valid = true`，该形式决定 Step 2 子项的权重配比，继续打分。
- **不属于给定 20 种**：`composition_form_valid = false` → **一票否决**（见下文），子项填 `null`，不再计子项加权。

若多种形式叠加，以**视觉主导**的那种为准，可在 `composition_form_reason` 备注叠加信息。

> **构图形式本身不占分值**——它的作用是：(1) 准入门槛；(2) 决定子项权重配比。

## Step 2 · 子项打分与加权（仅 Step 1 通过时执行）

对以下四个子项各打 **1–5 分**，按 Step 1 识别出的构图形式对应权重加权合成 `composition_score`：

```
composition_score = 框架留白 × w1 + 透视自然度 × w2 + 视觉引导线 × w3 + 动势与张力 × w4
```

权重 `(w1, w2, w3, w4)` 查下方「构图形式对照表」中对应行。满分 = 5.0。

# 一票否决

出现以下情况时，`veto_applied = true`，`composition_score` **强制为 1**，子项分数填 `null`，`weights_used` 填 `null`：

1. **构图类型不在给定类型**：画面无法归入上表 **20 种构图形式** 中的任何一种（`composition_form_valid = false`）。须在 `veto_reason` 写明「不属于给定构图类型」。
2. **总表构图美学硬伤**（与「总表」一致，子项可已打分）：水平线极度倾斜、主体被关节处切割、重心坍塌，导致基础视觉秩序崩坏。

触发否决后 **不得** 输出高于 1 的 `composition_score`。

# 子项一 · 框架留白

| 分数 | 档位 | 标准 |
|------|------|------|
| **5** | 极具叙事力 | 留白即语言：主体位置精确（黄金分割/对称），留白区域具备光影纹理或氛围感，通过引导/推拉为主体赋予了情绪属性（如孤独、辽阔） |
| **4** | 逻辑严谨 | 空间支撑稳健：留白让主体呼吸且通过对比消除背景干扰，比例符合美学法则，视线路径无阻碍，平衡感极佳 |
| **3** | 功能达标 | 基础避雷：满足"不挤压、不触边"原则，无逻辑性错误。视觉工整但缺乏对空间的深度利用，留白偏功能性 |
| **2** | 视觉冗余 | 留白无意义：大面积"无效空白"，既不衬托情绪也不构成引导，主体漂浮或孤立 |
| **1** | 结构破碎 | 逻辑崩坏：边缘截断语义部位、主体贴边溢出，画面缺乏物理安全空间，构图重心彻底缺失 |

# 子项二 · 透视自然度

| 分数 | 档位 | 标准 |
|------|------|------|
| **5** | 0 级偏差 | 几何基准重合：关键解剖点（头/肩/肘/膝）偏差 < 5%，视觉无非线性形变 |
| **4** | 轻微偏差 | 透视张力控制：畸变仅在非关键区，关键部位偏差 5%–10%，符合广角/长焦光学特性 |
| **3** | 可控偏差 | 光学特征表现：全局轻微桶形/枕形畸变，主结构连贯，偏差 10%–15% |
| **2** | 显著偏差 | 局部比例失调：关键部位（五官/肢体末端）非生理性拉伸/压缩，偏差 > 15% 且无叙事支撑 |
| **1** | 结构破碎 | 几何逻辑崩坏：偏差 > 25%，头颅/肢体严重失真，与物理现实脱节 |

# 子项三 · 视觉引导线

| 分数 | 档位 | 标准 |
|------|------|------|
| **5** | 全权调度 | 路径闭环：几何线/光影流/视线差构建强制性视觉闭环，路径本身即叙事一部分，视线在画面内循环，主体定位 100% |

| **2** | 噪声干扰 | 路径冗余：多条冗余视觉噪音致视线频繁脱轨或驻留无关区域 |
| **1** | 认知错位 | 逻辑崩塌：引导指向非叙事中心或画外，主体被淹没 |

# 严格策略

1. 先判 `composition_form_valid`：属于 20 种之一 → `true` 并继续 Step 2；不属于 → `false` → **一票否决，`composition_score = 1`**，子项全部 `null`。
2. **构图形式本身不占分值**，它仅作为准入门槛 + 决定子项权重。
3. `weights_used` 必须与对照表中该形式的权重**逐字段完全一致**（含小数位）；不属于时填 `null`。
4. `composition_score = 框架留白×w1 + 透视×w2 + 引导线×w3 + 动势×w4`，**保留 1 位小数**。满分 5.0。
5. "不规则/倾斜"构图属于给定 20 种之一，识别为该形式是正常准入（不是否决）。
6. 只输出一个 JSON 对象，禁止 markdown 代码块或额外文字。
