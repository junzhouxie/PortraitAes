# 风格定义补充（识别辅助知识）

以下为每个大类及其小类的详细定义、核心特点与识别重点。**判定时以此为知识参照**。

## I. 功能类

核心目的：满足特定社会活动、档案管理或职业展示的需求。这类照片通常要求严谨、客观、真实，以突出人物的职业身份或作为身份核验的凭据。

**识别重点**：
1. "去艺术化权重"：此类照片应降低"艺术表现力"的权重，将"画面清晰度"、"构图的对称性"、"曝光的准确性"设定为高分特征。
2. "职业标签关联"：建立知识库关联，将"听诊器"与"医生"、"法袍"与"律师"、"工牌"与"员工"等强相关元素纳入识别模型。
3. "面部特征提取"：此类照片主要功能是"识人"，对"五官清晰度"、"面部骨骼对称性"、"无遮挡情况"的识别应达到极高标准。
4. "背景简化度"：功能类照片背景应以纯净、低干扰为优。复杂背景（如街头、风景）为该类别的负样本。
5. "表情分析"：区分"中性表情"（证件类）、"自信表情"（商务类）与"亲和力表情"（面试类），表情特征是此类照片风格分类的重要判别维度。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 证件照 | 用于国家机关核验身份的照片。纯色背景（蓝、白、红为主），人物正视前方，无任何遮挡（露出耳朵和眉毛），光影均匀平铺（几乎无阴影），表情绝对中性 | 正视、平光、无影、蓝/白/红底、眉耳可见、绝对中性 |
| 商务头像 | 用于企业官网、个人主页、新闻通稿或商务演讲的展示照片。穿着正式（西装、领带），背景多为深色简洁墙面或虚化的办公环境，构图为胸部以上，光线细腻强调人物面部轮廓，眼神交流感强 | 正装、眼神交流、深色/虚化办公背景、专业自信感 |
| 简历照 | 贴在求职简历上的个人照片。构图介于证件照与肖像照之间，着装正式干练，背景通常为浅灰或浅蓝，表情呈现出亲和力与职业感 | 浅灰/蓝底、明亮、亲和力微笑、干练半身构图 |
| 演员模特档案 | 演员或模特向经纪公司、剧组展示自身可塑性的"卡片"照片，包含多组图（特写、半身、全身），妆容干净或素颜，着装贴身以展示身材比例 | 多组照对比、干净素雅、骨骼结构清晰、去表演化 |
| 工牌照 | 用于公司内部身份识别或考勤系统的照片。极简背景，构图紧凑（头部占比较大），光影高度简化 | 极致头部特写、极简、高辨识度、裁剪比例紧凑 |
| 面试社交头像 | 用于求职面试期间沟通工具或职业社交平台的头像。穿着干练但风格略微活泼，光影柔和，背景可能带有少许职业场景元素（书架、绿植） | 职场互动场景、柔和光影、友好且专业的社交距离 |
| 职业形象照 | 根据特定职业属性量身定制（律师/医生/讲师）。强行业属性识别（白大褂、法槌/法袍、书堆/黑板/话筒），背景呈现出明显的职业工作空间 | 行业道具（白大褂/法槌）、职业工作空间、权威感布光 |

## II. 商业类

核心逻辑："视觉营销"，其终极目标是辅助产品销售、提升品牌形象、引导消费欲望。

**识别重点**：
1. "材质识别"：强化对材质（丝绸、金属、皮肤、毛绒）的物理特性识别，商业摄影的本质就是对材质的"视觉美化"。
2. "无瑕感"权重：将"过度平滑的肤质"、"经过精修的边缘线"作为商业摄影的高置信度特征。区分"真实瑕疵"与"商业修饰"。
3. "排版空间识别"：商业图片通常会留出空白区域以供品牌添加文案或 LOGO，应识别这种"为设计预留"的构图。
4. "光影一致性"：商业摄影往往追求完美的光影布置（如三点布光法），应识别出画面是否存在非自然的人工布光痕迹（对称眼神光、极其规则的阴影过渡）。
5. "产品作为锚点"：无论画面多复杂，定位到画面中的"核心产品对象"，将其标记为画面的锚点，这是商业摄影区别于艺术摄影的重要逻辑。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 时装广告 | 为品牌季节性产品拍摄的宣传大片。电影级布光（高对比度或戏剧化光影），构图宏大或极具设计感，模特姿态夸张且具艺术张力 | 电影级剧场布光、夸张肢体艺术张力、过度精修、梦境感 |
| 电商 Lookbook | 展示当季全系列服装搭配的画册。呈现完整的搭配逻辑（上衣+下装+配饰），多为系列连贯构图，场景通常简洁 | 系列搭配逻辑、全身/七分身、背景统一极简、展示导向 |
| 美妆/护肤特写 | 聚焦于模特面部，展示彩妆颜色质地或护肤后皮肤状态。极致微距或半身特写，皮肤纹理呈完美质感 | 极致微距、皮肤纹理毛孔级清晰、水光/哑光质感、眼神光 |
| 首饰/配件特写 | 专拍项链、耳环、手表、包包等配饰。聚焦金属光泽、宝石火彩或皮革纹理，通常采用深色或质感背景 | Rim light（轮廓光）、背景全虚、材质金属/宝石折射 |
| 珠宝奢饰品人像 | 将昂贵珠宝与人物佩戴相结合的肖像拍摄。人与物比例协调，模特呈现贵气/冷峻/高雅气质 | 浓郁贵气色调、高光点突出宝石、冷峻高贵气质 |
| 品牌代言人海报 | 品牌聘请明星或网红拍摄的形象海报。显著品牌 LOGO 或视觉标识，高认知度面孔 | 明星脸、Logo/Slogan 视觉锚点、规则居中构图 |
| 服装型录 | 以展示每一件单品细节为目的。标准正面/侧面/背面视图，背景纯白或浅灰，光影均匀无明显投影 | 标准的正/侧/背三面、无投影、面料细节清晰、说明性强 |
| 内衣/泳装拍摄 | 展示内衣或泳装产品。强调人体线条与肌肉轮廓，光线设计旨在突出身体曲线的张力与服饰剪裁贴合度 | 身体线条张力、肌肉/曲线美、光影雕塑感、服饰剪裁吻合 |

## III. 叙事类

核心在于"真实性"与"情绪价值"，通过定格瞬间来讲述一个关于时间、情感或事件的故事。

**识别重点**：
1. 关注"摆拍检测"：识别"视线回避"（人物不看镜头），将其作为"非摆拍/纪实感"的重要加分项。
2. 环境叙事权重：不要将背景中的建筑、装饰视为干扰，而应将其标记为"叙事上下文"，这是区分"叙事类"与"功能类"肖像照的关键。
3. 情感强度计算：增加对面部微表情（如眼角的纹路、嘴角上扬的弧度）的特征提取权重，这是叙事类照片情感价值的量化依据。
4. 画质宽容度：不要以"高清晰度"或"轻噪点"作为评价标准，纪实摄影中的动态模糊是记录真实瞬间的必然结果，属于该类别的有效特征。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 婚礼纪实 | 在婚礼过程中捕捉真实发生的每一个瞬间，而非摆拍。包含婚礼仪式元素（婚纱、西装、仪式台、戒指、花艺），人物表情呈现非摆拍的真实情感流露 | 真实哭笑、仪式瞬间、非摆拍群体互动、氛围光 |
| 家庭生活记录 | 记录家庭成员在家中或户外共享天伦之乐的日常生活状态。居家室内环境，强调人物间低互动距离 | 家居乱序、低距离接触、温馨暖调、生活杂物堆叠 |
| 孕期纪念 | 记录准妈妈在孕育生命阶段的身体形态和情感期待。人物姿态多为侧面或半侧面以突出曲线 | 侧面侧影、腹部隆起、轻抚动作、静谧柔和感 |
| 亲子互动 | 捕捉父母与孩子之间真实的游戏、抚摸、拥抱等互动。明显身高差，人物视线焦点在对方身上而非镜头 | 玩耍/奔跑动态、视线非镜头、童真与看护者的连接 |
| 成人仪式纪念 | 针对成人礼、毕业礼等人生重要节点的专题记录。标识性礼服（学士服、成人礼服装） | 标志性仪式礼服、成长蜕变感、笃定成熟神情 |
| 旅拍叙事 | 在旅途中记录人与环境、风景的融合，展现异地风情与个人探索。人物与显著异地风情背景的融合 | 异地标志性背景、探索姿态、人与风景的互动融合 |
| 社会人文纪实 | 观察并记录特定社会群体或文化现象的影像。极具现场感的街头或公共空间，冷峻旁观视角 | 旁观视角、丰富背景信息、冷峻光影、社会状态切片 |
| 活动跟拍 | 对论坛、派对、赛事等活动的记录。包含会议/讲座/表演或社交活动特征 | 话筒/演讲台/聚光灯、事件关键帧、流程性视觉记录 |
| 访谈人物记录 | 配合访谈场景，记录受访者的神情与对话状态。典型的近距离半身特写，人物带有深度思考神情 | 近距思考神情、虚化书房/专业背景、深刻眼神交流 |
| 影视截图 | 取自电影或电视剧中的人物帧画面。没有进行二次创作的图片，具有高度电影感的影调、画幅比例（如 2.35:1），戏剧化构图 | 2.35:1 画幅、戏剧性冲突、工业级电影布光、色调调色 |

## IV. 审美类

核心在于"感官表达先于逻辑叙事"。这类图片的拍摄目的是为了营造特定的视觉氛围，让观众产生某种"美感共鸣"。

**识别重点**：
1. 风格饱和度监测：不要将审美类图片中的"色彩偏差"视为后期错误或色彩还原不准。需识别特定风格的"色彩偏移规律"（如：日系偏蓝青、胶片偏黄绿、Ins 风格偏高反差）。这是一种"预设的审美倾向"，是该类别的核心特征，而非干扰项。
2. 服装语境优先级：审美类的判定应极度依赖"服饰符号"。将"汉服/旗袍"、"JK/制服"、"机能风服装"标记为高权重特征标签。当画面中出现强烈的制服类元素时，该图片即刻锁定为对应的审美细分类别（如古风、学院风），无需进一步纠结其环境属性。
3. 氛围光影的"非自然干预"识别：与叙事类追求"自然光"不同，审美类常伴随"滤镜感"或"刻意布光"。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 日系清新/空气感 | 模仿日本杂志人像，强调光线通透和情绪的"呼吸感" | 高调（明亮）、过曝的高光、低对比度、色彩清透（偏青/蓝）、背景虚化柔和 |
| 胶片复古/怀旧 | 模拟传统胶片相机成像，追求岁月沉淀与人文记忆 | 胶片颗粒感、暗角、漏光痕迹、色彩偏移（黄/绿调）、高宽容度导致的细节平滑 |
| 新中式/古风 | 融合东方美学与现代构图，表现汉服、旗袍等传统服饰美 | 典雅构图、留白、柔和且考究的光影、传统色系（朱红/青绿）、团扇/屏风等古典意象 |
| 洛丽塔/JK/学院风 | 以特定制服符号为载体，表现青春、二次元或精致童话感 | 饱和度适中、服装剪裁线条清晰、强烈的角色扮演符号、光线均匀明亮 |
| 街头潮流 | 展现城市边缘或时尚街头的叛逆与前卫美学 | 广角畸变、涂鸦背景、复杂光影、高对比度、冷峻粗糙的纹理、叛逆眼神 |
| 欧美/Ins 风格 | 模仿 Instagram 头部博主审美，追求极度的精致与锐度 | 强对比、深邃阴影、极高锐度、精致完美妆容、自信且张扬的姿态、时尚感强 |
| 森系/自然光 | 以自然环境为背景，追求人与自然的和谐与野性融合 | 绿植背景、漫反射自然光（丁达尔效应）、慵懒状态、大地色/原色调、呼吸感强 |

## V. 社交类

核心在于高质量的"自我表达"与"社交货币"。主要发布平台是朋友圈、小红书、Instagram 等，旨在展现个人生活方式、审美趣味以及与他人的连接。核心逻辑："好看"是基础，"共鸣"和"点赞"是目的。为拍摄后再精修，最后展现出来的图片；属于极高质量的人像摄影类型。

**识别重点**：
1. 社交类摄影中，过度的后期修饰（如一键美颜）不是缺陷，而是这类风格的"默认属性"。不应过度追求去噪或真实肤质，应识别这种"高度修饰的美"。
2. 引入"场景上下文"关联：社交照片很大程度上由"场景"定义。强化场景识别，当画面识别出"餐厅"、"草地"、"健身房"等关键词时，需优先将其归入社交类。
3. 重视"肢体语言的松弛度"：社交类摄影（尤其是抓拍和生活照）的核心是"不紧绷"。需识别身体动作的僵硬度（摆拍感）与松弛度（自然感）。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 高质量自拍 | 通过精心构图、光线及后期，在独处状态下拍摄的个人肖像 | 精致美颜、侧脸精修、眼神高光、展示个人门面 |
| 对镜自拍 | 利用镜面反射拍摄自己，通常会露出手机 | 手机镜面反射、展示手机/穿搭/空间、随意符号 |
| 多巴胺/高饱和感 | 采用鲜艳、明亮、强对比的色彩组合，营造视觉兴奋感（自拍及他拍） | 鲜艳色彩组合、强明度、视觉兴奋、愉悦的情绪输出 |
| 夜景霓虹风 | 在夜晚的城市街头，利用霓虹灯、车流灯光作为背景拍摄（自拍他拍） | 背景光斑（Bokeh）、冷暖光对比、城市孤独感/潮流感 |
| 网红景点打卡 | 在社交媒体上热门的地标性建筑或景观前拍摄的精品照片 | 地标物、标准式网红打卡姿态、高辨识度、精品修饰 |
| 探店风 | 在特色餐厅、咖啡馆、艺术空间拍摄的精致照片 | 场景精致小资物（咖啡/艺术品）、生活美学氛围感 |
| 野餐/露营感 | 在户外露营、草地野餐背景下拍摄的照片 | 户外道具（帐篷/垫子/水果）、逃离城市感、松弛 |
| 节日主题妆面照 | 针对特定节日（万圣节、圣诞节、情人节等）拍摄的具有仪式感的妆容和造型照 | 特定符号物（装饰灯/彩妆元素）、极强仪式感 |
| 运动健身打卡照 | 在健身房、运动场或居家运动时记录身体训练状态或运动成果的照片。需与正式比赛的运动员摄影区别开，此标签更偏向社交作用 | 肌肉/马甲线、运动后流汗光泽、器械背景、励志感 |
| 视频截图/氛围感抓拍 | 从视频记录中截取的、具有极强氛围感的单帧画面，或故意模拟视频动态抓拍的"伪静态"图。多为明星影视/演唱会高质量二创作品，需区别正常影视作品 | 动态模糊、不经意切片、沉浸真实、电影叙事感 |

## VI. 艺术类

核心在于"表达先于记录"。摄影师不再仅仅是现实的搬运工，而是将摄影作为一种视觉语言，去探索哲学、心理、梦境或纯粹的审美形式。

**识别重点**：
1. 影调与影调比：高调或低调的处理方式。
2. 构图的异常性：是否打破了传统视觉规律。
3. 色彩的脱离感：颜色是否服务于情绪而非真实世界的还原。
4. 画面符号：画面中是否出现了非日常的元素组合。
5. 不要只找"对象"：不要只识别图片里有一个人，要识别"人像姿态是否具有仪式感"、"光线是否在强调某种哲学意图"。
6. 可以尝试引入"风格参照集"：在识别中加入美术史上的经典意象（如包豪斯构图、表现主义用光），从而在处理现代艺术摄影时，能识别出背后的审美逻辑。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 观念人像 | 围绕一个特定的抽象概念（孤独、自由、时间）来创作的人像作品 | 隐喻符号（如蒙眼/悬浮）、哲学意图、解码思维 |
| 艺术人体 | 将人体视为一种纯粹的结构与线条美进行创作的艺术 | 几何线条美、去脸部化、宁静雕塑感、肌理写实 |
| 超现实主义 | 捕捉或后期创造出一种打破现实逻辑、如同梦境般的画面 | 违背逻辑的比例/空间、梦境感、悖论重组 |
| 黑暗/哥特 | 倾向于表现忧郁、死亡、神秘或颓废美学的创作 | 极高对比、压抑暗色调、蕾丝/仪式、神秘死亡美学 |
| 负片艺术 | 将拍摄照片的色彩或明暗完全反转（底片化）的视觉实验 | 色彩明暗倒置、假彩色、异样感 |
| 慢门/光绘 | 通过长时间曝光，记录光线运动的轨迹 | 轨迹线、动静结合、时间堆叠轨迹感 |
| 双重曝光 | 将两张或多张图像叠加在同一底片或画布上 | 空间融合、纹理与轮廓叠加、虚实重叠 |
| 极简主义肖像 | 极度精简画面元素，仅保留最核心的主体，拒绝多余干扰 | 负空间比例极大、纯粹聚焦、克制用光 |

## VII. 综合类

这类摄影不仅是"拍摄"，更是"创作"与"重构"。它将摄影作为一种基础媒介，与其他艺术形式（绘画、装置、数字算法、化学处理）深度碰撞，探讨的是摄影的极限。

**识别重点**：
1. 关键识别指标：识别"非自然产生的畸变"（如 AI 痕迹）、"物理受损痕迹"（如胶片划痕、烧灼感）、以及"非摄影元素"（如叠加的拼贴画纹理、文字涂鸦）。
2. 逻辑权重：对于此类图片，权重应从"对焦清晰度"和"构图法则"转移到"画面表现的独特视觉特征"上。它们不需要完美的清晰度，而是需要极强的"视觉辨识度"。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 跨界拼贴/混合媒体 | 将摄影照片与绘画、拼贴、文字、甚至织物等实体媒介进行物理或数字上的二次组合 | 物理切割、涂鸦/文字叠加、多媒介层次感 |
| AI 融合人像 | 将传统拍摄的人像照片与 AI 算法结合，通过生成式 AI 进行风格化重塑、局部扩展或深度合成 | 超现实肌理、发光皮肤、计算摄影造成的视觉畸变 |
| 实验性空间人像 | 在非常规空间环境（废墟、反光材料构筑的迷宫、极端建筑几何中）拍摄的人像 | 建筑几何畸变、人与极端结构的张力 |
| 梦境/意识流叙事 | 放弃线性叙事逻辑，通过非连贯意象组合，展现梦境般的破碎感或内心深处的意识流动 | 非线性、破碎意象组合、心理非理性表达 |
| 胶片化学破坏实验 | 在冲洗胶片的过程中，人为加入酸、碱、肥皂水、热力等化学手段，破坏乳剂层 | 胶片烧灼痕迹、划痕、霉斑、随机色彩异常 |
| 多媒介装置人像 | 将人像照片以投影、灯箱、雕塑等装置形式呈现，或将人像拍摄作为装置艺术的一个环节 | 投影/灯箱/实体装置交互、三维空间感 |
| 无定义/实验性影像 | 不属于任何已知分类，甚至对"什么是摄影"本身提出质疑的影像尝试 | 纯粹视觉震动、超越传统成像定义的视觉语言 |

## VIII. 随手拍

最有生命力的类别。核心价值在于"去审美化"和"去门槛化"，记录的是生活最真实的切片。

**识别重点**：
1. "不完美性"：画面中常出现的非标准构图（如稍微歪斜的地平线）、低光照环境下的噪点、轻微的动态模糊。这些"瑕疵"在随手拍中不是扣分项，而是加分项。
2. "生活感"：画面中是否包含生活道具（钥匙、背包、手机、饮料、乱序的背景）。
3. "真实度"：排除影棚光影和精致的妆造感，更偏向自然光、室外光。
4. "即时性"：识别出画面中人物的动作是否处于某种未完成的连续动作中。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 自然态 | 在不经意间记录人物在生活中的放松状态，没有任何摆拍指导，没有后期二次加工的照片 | 真实、非摆拍、没有任何后期痕迹、生活感 |
| 动态抓拍 | 在运动、行走、谈笑等动态过程中迅速按下快门 | 动作瞬间、轻微运动模糊、生命力表达 |
| 手机前置自拍 | 使用手机前置摄像头（通常带美颜/滤镜）拍摄的个人影像。区别于社交类自拍，手机前置自拍属于没有二次精修过的人像，整体质量偏低，更注重情绪表达 | 独特广角五官畸变、直接互动感、像素原生感 |
| 大头自拍照 | 近距离拍摄的面部特写，通常占据画面大部分空间 | 距离近、五官直接冲击、背景叙事缺失 |

## IX. 符号类

"去原图化"与"表情包社交"。在这一类别中，照片已经脱离了单纯的视觉记录功能，转变为一种社交语言。它们不再追求光影构图的完美，而是追求表达的准确性、幽默感或传播性。

**识别重点**：
1. 非审美维度：识别画面中的"语义内容"。需能够理解"文字内容"与"画面情绪"的匹配度，而不仅仅是判断画面是否好看。
2. 社交属性：画面是否具备传播潜力？（例如：画面中是否有夸张的表情、是否有文字占位符）。
3. 视觉破坏度：应学习将"抠图"、"变形"、"过度饱和"视为特征而非噪声。符号类影像往往具有很高的视觉噪点（如人工添加的贴纸、文字重叠）。
4. 语境依赖：符号类影像通常是"上下文依赖"的，需理解图片背后的文化梗，理解为什么某张"崩坏"的照片可以作为一种社交表情存在。

| 小类 | 定义 | 核心特点 |
|------|------|----------|
| 动态 GIF | 通过循环播放的短动图，截取某个特定动作或表情，形成极短的叙事循环 | 循环播放、动作循环、高频语义表达 |
| 文字贴图 | 在图片上添加文字（吐槽语、金句、状态标签），使原有视觉内容产生新含义 | 语义解释、吐槽/金句、定义语境的文字载体 |
| 二创修图 | 在原图基础上进行夸张化后期（五官变形、添加诡异装饰、深度解构或合成） | 变形、解构、荒诞玩梗、破坏审美框架 |
| 表情包模版 | 具有固定结构、逻辑框架或视觉构图的影像载体（对比图、四格叙事、模板式吐槽） | 固定结构、模版化逻辑、互联网传播图式 |
